## Етап 1. Сьогодні: локально на комп’ютері

### Підготовка (5 хвилин)
1. Потрібен Node.js 22+ (nodejs.org → LTS).
2. Розпакуй архів → `start-test.bat` (тестовий стенд: окрема база, готові входи) або `start.bat` (чиста база, як буде на Railway).
3. Панель відкриється в браузері (`http://localhost:3001` для стенда, `http://localhost:3000` для чистої).
4. **Telegram-бот:** увійди як адмін → «Telegram і функції» → встав токен від @BotFather → «Зберегти токен».
   Токен у файли не пиши й нікому не пересилай.

Входи тестового стенда (пароль у всіх `test12345`): `admin@test`, `owner@test` (тімлід), `operator@test` (оператор).
Сайт для бота на стенді: `…/demo-site/shift.html` (дві жінки, «Шанс» і «Аллчат»).

### А. Реєстрація й команда (на `start.bat`, чиста база)
1. Адмін → «Реєстрації» → «+ Запросити тімліда» → скопіюй посилання.
2. Відкрий посилання в іншому браузері (або інкогніто) → ім’я, email, пароль.
   → Одразу з’являється вікно **«Як назвемо вашу команду?»** → назва → потрапляєш на головну.
3. Тімлід → «Команда» → «Скопіювати повідомлення» → відкрий посилання ще в одному вікні → зареєструй оператора.
   → Оператор бачить «Заявку надіслано», увійти ще не може.
   → У тімліда в «Команді» з’являється «Чекають підтвердження» (і повідомлення в Telegram, якщо тімлід його підключив).
4. Тімлід → «✓ Підтвердити» → оператор входить.
5. «Забули пароль?» на сторінці входу → email оператора.
   → Посилання приходить у Telegram (пошта локально не налаштована) → новий пароль → старі входи скинуто.

### Б. Telegram — у кожного своє
1. Тімлід і оператор: «Головна» → «Підключити Telegram» → у боті «Старт».
2. → Кожен бачить лише свої звіти й кнопки: 📊 Звіт, 🤖 Стан, ▶️ Старт, ⏹ Стоп.

### В. Години зміни: автостарт і автостоп
1. Тімлід → «Налаштування» → «⏰ Години зміни».
   Для денного тесту постав так, щоб **зараз була зміна** (наприклад 10:00–22:00) → «Зберегти».
2. Оператор → «Налаштування» → «Мій початок / кінець»: спробуй години поза межами тімліда.
   → Помилка «в межах зміни команди». Години всередині зберігаються.
3. Оператор: «Завантажити бота» → `chrome://extensions` → «Режим розробника» → «Завантажити розпаковане» → тека бота → вхід у боті.
4. Відкрий сайт (на стенді — демо `shift.html`) і не натискай нічого.
   → Протягом хвилини бот **сам** вмикається: «⏰ Початок зміни — вмикаюсь сам».
   → Спершу «Шанс», потім чекає відповідей, кілька разів за ніч — «Аллчат». Після кожної розсилки звіт у Telegram.
5. Тімлід → переносить кінець зміни на «зараз» (найближча година, що вже минула).
   → На наступному «пульсі» (≤1 хв) бот сам вимикається: «⏰ Кінець зміни — вимикаюсь до наступної».
6. Поза зміною ▶ у панелі, у Telegram і в боті → чітка відповідь «Зараз не зміна (…)». 🧪 тест працює завжди.
7. Ручний ⏹ посеред зміни → бот не вмикається сам до наступної зміни (▶ вручну — працює).

### Г. Що може тімлід з оператором («Команда»)
1. «🤖 Бот ✓» → «Призупинити» + причина.
   → У оператора бот зупиняється й не входить; у Telegram — повідомлення з причиною; панель працює. Повернути — та сама кнопка.
2. «🧠 ШІ ✓» → вимкнути.
   → Повідомлення в Telegram; бот працює далі, тексти з шаблонів. Увімкнути назад.
3. Відкрий оператора → «Видалити з команди».
   → Вхід у панель і бота закрито одразу, Telegram-повідомлення, анкети лишились у команді.

### Д. Мова UA / RU
1. Сторінка входу: перемикач UA | RU (до входу).
2. «Налаштування» → «🌐 Мова» → Русский.
   → Панель російською; вікно бота російською (після наступного відкриття); кнопки й звіти в Telegram — російською.

### Е. Справжній сайт (без надсилання)
1. Адмін → «Команди» → картка команди → вкладка «Сайт» → адреса сайту → «Поставити готовий профіль».
2. Оператор → вкладка сайту, вхід в анкету → у вікні бота «🧪 Тестовий режим» → «Запустити тест».
   → Бот проходить Шанс і Аллчат по всіх жінках, нічого не надсилає; звіт із прикладами текстів — у Telegram.
3. Якщо тест чистий — коротка справжня зміна на 1–2 години (години в Налаштуваннях) і подивитись звіти.

## Етап 2. Після запуску на Railway

### Запуск
1. Railway → New Project → цей репозиторій → сервіс → Volume на `/data`.
2. Змінні (Variables):
   - `ADMIN_PASSWORD`;
   - `DEMO_SITE=0`;
   - `ANTHROPIC_API_KEY` — ключ платформи (за бажанням: тімлід може поставити свій);
   - `SMTP_URL` і `MAIL_FROM` — для «Забули пароль?» на пошту (Gmail: пароль застосунку, `smtps://логін:пароль@smtp.gmail.com:465`);
   - `TELEGRAM_BOT_TOKEN` — або встав токен в адмінці, як на етапі 1.
3. Відкрий адресу `…up.railway.app` → вхід адміна → «Telegram і функції»: бот і пошта «✅».

### Що перевірити
1. Усе з етапу 1 (А–Е) — уже з телефона й різних комп’ютерів операторів.
2. Повна нічна зміна з реальною командою: автостарт о початку, автостоп о кінці, звіти кожному свої.
3. «Забули пароль?» → лист на email (перевір «Спам»).
4. Оновлення бота (зробимо, коли буде перша правка):
   → поза зміною кожному приходить «🆕 Нова версія бота»;
   → стара копія не стартує й пише, що робити;
   → бот, що вже працює, доробляє зміну.
5. Адмін → «Пристрої й копії бота»: видно кожну копію; «Вимкнути копію» → цей бот більше не входить.
6. Захист:
   - 10 неправильних паролів → «Забагато спроб входу»;
   - злите посилання оператора → без підтвердження тімліда людина не входить;
   - «↻ Нове» посилання → старе не працює.

### Що НЕ перевіряється тестами автоматично (лише руками)
- Справжній сайт знайомств (NDA): селектори, капча, лічильники листів.
- Справжні тексти Claude (у тестах — підміна).
- Справжня пошта Gmail / іншого поштовика.
- Доба безперервної роботи браузера з ботом.
