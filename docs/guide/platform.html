1. Railway — панель в інтернеті тобі

  1. Відкрий railway.com → Login → Login with GitHub.
  2. New Project → Deploy from GitHub repo → вибери репозиторій crm.
    + New Project→Deploy from GitHub repo→rytmique/crm
    Не бачиш репозиторій — натисни «Configure GitHub App» і дай доступ саме до нього.
  3. Railway сам збере панель. Чекай, поки сервіс стане зеленим (Active), 2–4 хв.
  4. Диск: правий клік по сервісу (або + Create) → Volume → шлях /data → Create.
    Mount path/dataCreate

    ⚠ Без диска всі дані зникнуть після першого ж оновлення.

  5. Variables → New Variable, додай:
    ADMIN_EMAILтвій email
    ADMIN_PASSWORDпароль, мін. 8 символів
    ANTHROPIC_API_KEYнеобов’язково — див. частину 2
  6. Settings → Networking → Generate Domain. Отримаєш адресу на кшталт https://crm-production-1234.up.railway.app. Це і є панель.
  7. Відкрий адресу → увійди своїм ADMIN_EMAIL і ADMIN_PASSWORD. Бачиш «Огляд» — готово ✅

Оновлення: коли я пушу зміни в main, Railway оновлюється сам за 1–2 хв. Нічого робити не треба.

Забув пароль: додай змінну RESET_ADMIN_PASSWORD з новим паролем → увійди → видали змінну.

2. Ключ ШІ (Claude)

  1. Відкрий console.anthropic.com → зареєструйся.
  2. Billing → Add credits (від $5).
  3. API Keys → Create Key → назва crm → скопіюй ключ sk-ant-…. Його показують лише раз!
  4. Куди вставити — вибери одне:

    а) Один ключ на всю платформу (простіше): Railway → Variables → ANTHROPIC_API_KEY. Усі команди пишуть твоїм ключем, а хто скільки використав, видно в «Пульті».

    б) Свій ключ у команди: тімлід → «ШІ» → «Ключ Claude» → вставити → «Зберегти». Там же — вибір моделі і хто скільки використав.

Без ключа бот пише простими шаблонами: працює, але гірше. З ключем — живий лист під кожну анкету й повідомлення на тему розмови.

3. Telegram-бот звітів тобі, один раз

  1. У Telegram відкрий @BotFather → /newbot → назва → юзернейм (має закінчуватися на bot).
    /newbot
    Alright, a new bot. How are we going to call it?
    Agency Reports
    Good. Now let's choose a username for your bot. It must end in `bot`.
    agency_reports_bot
    Done! … Use this token to access the HTTP API: 123456789:AAH••••••••••••••••••
  2. Панель → «Telegram і функції» → встав токен → «Зберегти токен». З’явиться «✅ Працює: @agency_reports_bot».
  3. Там же натисни «Підключити мій Telegram» → відкриється бот → Start.

Далі кожен у панелі (внизу «Головної») тисне «Підключити Telegram» → Start, і отримує свої звіти: оператор — по своїх анкетах, тімлід — по команді. Так виглядає звіт після кожної розсилки:

✅ 🎯 Шанс · Kate Листів з фото: 8 (онлайн 12, уже писали 4) За ніч: Шанс 8 · Аллчат 4 · відповідей 3 · 12 хв
✅ 💬 Аллчат · Kate Повідомлень на тему розмови: 4 з 14 діалогів Пропущено: чекають відповіді людини 4 · ще не замовкли 6 За ніч: Шанс 8 · Аллчат 4 · відповідей 3 · 9 хв
📊 Звіт🤖 Стан▶️ Старт⏹ Стоп

Кнопки внизу чату: звіт за ніч, що зараз роблять боти, запуск і зупинка. Кожен керує тільки своїми анкетами, а чужий Telegram без підключення не має доступу ні до чого.

«🔒 Бот сам продовжує розмову після відповіді» поки закрито для всіх. Відкриєш тут, коли будемо готові.

4. Команда клієнта тобі

  1. «Команди» → «+ Запросити тімліда» → скільки анкет у плані → скопіюй посилання → скинь тімліду.
  2. Тімлід реєструється за посиланням → ти підтверджуєш у «Реєстрації».
  3. Клік по команді → вкладка «Сайт» → впиши адресу сайту (лише домен) → «Поставити готовий профіль». Усе: бот знає цей сайт, команді нічого налаштовувати не треба.
  4. Клік по команді → її картка: план, люди, ШІ, пристрої. Закрити доступ окремій людині — «Блок» (її боти зупиняться, вона вилетить звідусіль). «⏹ Стоп» — зупинити її ботів, «Вийти скрізь», «Пароль».

5. Для тімліда можна переслати йому

У меню всього 4 пункти: Головна, ШІ, Команда, Налаштування. Анкет вручну не додаєш — бот сам бере їх із сайту.

  1. Увійди за посиланням від постачальника. Якщо є свій ключ ШІ — «ШІ» → вставити → «Зберегти». Там же модель: Opus (найкращі тексти), Sonnet, Haiku (найдешевше).
  2. «Команда» → скопіюй посилання для операторів → скинь їм → підтверди, коли зареєструються.
  3. «Налаштування» → «Нічна зміна» — для всієї команди:

    🎯 Шанс — раз на 30 хв (змінюється) лист-інвайт з фото кожному онлайн-чоловіку, кому ще не писали.

    💬 Аллчат — 2–3 рази за ніч повідомлення на тему вашої розмови в постійні чати. Кому саме: «Хто замовк», «Хто колись відповідав» або «Усім чатам».

    Бот ніколи не пише туди, де чоловік чекає відповіді, і не відкриває непрочитані: відповідає жива людина.

    Там же мастер-промпт команди і «📷 Фото для Шансу» (анкети з’являються там самі, щойно бот уперше відкриє сайт). «Зберегти».
  4. «Головна»: ▶ / ⏹ для всіх, хто скільки зробив (по людях і по ночах), конверсія, що зараз робить кожна анкета. Клік по людині — її статистика. Унизу — «Підключити Telegram».

6. Для оператора

  1. Панель → зліва внизу «⬇ Завантажити бота» → розпакуй архів (папка agency-bot).
  2. Chrome → chrome://extensions → праворуч угорі «Режим розробника» → «Завантажити розпаковане» → вибери папку agency-bot.
    Режим розробникаON
    Завантажити розпакованеЗапакувати розширенняОновити
  3. Значок бота (пазл 🧩 → 📌) → адреса панелі, email, пароль → Увійти.
  4. Відкрий сайт і зайди. Перший раз постав «🧪 Тестовий режим» → «Запустити тест»: бот сам знайде всі твої анкети на сайті, пройде шлях за кожну й нічого не надішле.
  5. Зніми галочку → «▶ Увімкнути». Бот працює по всіх анкетах по черзі: сам перемикає анкету на сайті, кожній — свій Шанс і Аллчат. Далі вмикати можна і з панелі чи Telegram (▶).
  6. У панелі в оператора 2 пункти: «Головна» (своя статистика й ▶/⏹) і «Налаштування» — свій мастер-промпт, як часто Шанс, скільки разів Аллчат, фото для Шансу.
  7. Браузер має бути відкритий усю зміну. Якщо вилізе капча, бот стане на паузу й напише в Telegram. Розв’яжи її, і далі він піде сам.

7. Звіти й статистика

«Головна» показує все: скільки листів у «Шансі» й повідомлень в «Аллчаті», скільки відповіли, конверсію по ночах і по кожній анкеті. Тімлід бачить і свою, і загальну, і по кожному оператору. Скільки ШІ використано — на сторінці «ШІ».

У Telegram те саме коротко: звіт після кожної розсилки і кнопка «📊 Звіт» за ніч.
