# Agency CRM — панель команди + бот нічної зміни

Софт для агенцій на платних сайтах знайомств:

- **Панель** (`server/` + `web/`):
  - адмін платформи — команди, реєстрації, пристрої й копії бота, Telegram;
  - тімлід — команда, години зміни, ШІ, налаштування;
  - оператор — свої години, промпт, Telegram.
- **Бот** (`extension/`) — розширення Chrome:
  - сам вмикається на початку зміни: «Шанс» (інвайт + лист) → чекає відповідей → кілька разів за ніч «Аллчат»;
  - сам вимикається в кінці зміни;
  - звіти й нові відповіді — кожному у свій Telegram.
- Мови: українська / російська (панель, бот, Telegram).

## Запуск
| Що | Як |
|---|---|
| Тестовий стенд (готові входи, демо-сайт) | `start-test.bat` або `npm run test-stand` → http://localhost:3001 |
| Чиста панель на своєму комп’ютері | `start.bat` або `npm start` → http://localhost:3000 |
| Railway | репозиторій → Railway, Volume `/data`, змінні — у `.env.example` |

## Перевірка
```bash
npm install
npm test            # API-тести
npm run e2e         # справжній бот у Chromium: нічна зміна на демо-сайті
npm run e2e-desk    # бот на макеті «робочого столу» оператора
```

- План ручних тестів (сьогодні локально + на Railway): [`docs/TESTS.md`](docs/TESTS.md).
- Інструкція запуску з картинками: `python3 tools/build-guide.py out.html`.
- Усе для розробника — у `CLAUDE.md`.
